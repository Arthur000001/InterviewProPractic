# 🚀 Personal InterviewPro

**Personal InterviewPro** — это автономная база знаний и интерактивная платформа для подготовки к техническим собеседованиям на позиции Middle+ / Senior / TechLead. 

Проект спроектирован как статичный веб-сайт (HTML/CSS/JS), который не требует бэкенда и легко открывается локально в браузере.

## 🎯 Ключевые возможности
- **Индивидуальная база по компаниям**: Детализированные списки вопросов, актуальные для прохождения собеседований в конкретные IT-компании (например, Флант, Озон).
- **Скрытые ответы (`<details>`)**: Удобный формат для самостоятельной проверки знаний.
- **Интерактивные квизы (Quizlet)**: Встроенные скрипты для случайного перемешивания вопросов и проведения симуляции собеседования.
- **Широкий спектр дисциплин**: Linux & ОС, Сети, Kubernetes, Docker & CI/CD, Базы данных (SQL/NoSQL), Observability, GoLang, Архитектура и Soft Skills.

## 📂 Структура репозитория
В проекте используется нестандартная файловая структура для удобства работы с контентом:

- `scripts/` — скрипты логики квизов (`.js`).
- `styles/` — файлы стилей (`.css`).
- `view/` — **Внимание: здесь лежит главная страница!** Содержит `index.html` и базу знаний, разбитую по компаниям (например, `view/flant/`, `view/ozon/`).
- `.agents/` — директория, содержащая правила, память и Python-скрипты для автоматизации работы AI-агентов в этом репозитории.
- `.notes/` — справочная и мета-информация.

## 🚀 Как начать работу
Проект не требует установки npm-зависимостей, сборки или запуска веб-сервера. 
Чтобы начать подготовку, просто откройте файл `view/index.html` в любом браузере (например, Chrome или Safari).

## 🤖 Инструкция для AI-Агентов
Если вы — AI-ассистент, пожалуйста, **в первую очередь ознакомьтесь с файлом `AGENTS.md`** в корне репозитория перед тем, как предлагать или вносить какие-либо правки.
