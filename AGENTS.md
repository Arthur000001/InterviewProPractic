# Правила работы агентов (InterviewPro)

Приветствую, агент! Это проект InterviewPro. При работе в данном рабочем пространстве строго соблюдайте следующие инструкции:

## 📂 Структура проекта
Внимание: структура проекта **нестандартная**. Главная страница находится не в корне!
- `scripts/` — скрипты логики (`quizlet_mode.js` и др.).
- `styles/` — файлы стилей (`style.css` и др.).
- `view/` — здесь лежит главная точка входа `index.html` и директории с вопросами по компаниям (например, `view/flant/`, `view/ozon/`). Все внутренние HTML-страницы ссылаются на ресурсы из `scripts/` и `styles/`.
- `.agents/` — здесь лежат дополнительные инструменты, скрипты на Python и расширенные инструкции.
- `.notes/` — справочная информация.

## ⚠️ Критические ограничения
1. **Использование Терминала:** Разрешено использовать терминал и запускать скрипты. Ограничения сняты.
2. **Точечные правки:** Вносите изменения осознанно, желательно после предварительного просмотра через `view_file`.
3. **Расположение скриптов:** Все скрипты проекта должны находиться строго в директории `scripts/` (разносить их по проекту нельзя). Исключение: скрипты, предназначенные для ИИ-агентов, должны писаться на Python и сохраняться в директории `.agents/`.

## 📚 Расширенные правила
Обязательно ознакомьтесь с файлом `.agents/rules/interviewpro.md`, в котором содержатся детальные архитектурные ограничения и информация по проекту. Актуальный контекст сессий может находиться в `.agents/memory/CONTEXT.md`.
