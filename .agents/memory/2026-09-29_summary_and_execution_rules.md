## 2. Анализ сбоев и узких мест
- **Спам модальными окнами:** В IDE включено подтверждение команд терминала. Каждый вызов `run_command` блокировал экран пользователя модалкой («Allow running...»).
- **Раздел noexec:** Файловая система `/media/artur/...` смонтирована с `noexec`. Попытки прямого вызова `.venv/bin/python` падали с ошибкой 126.
- **Оверинжиниринг и медлительность:** Создание скриптов и тяжелых zip-бэкапов на каждый чих отнимало минуты вместо секундных правок.

## 3. Фиксация нового регламента
1. `run_command` запрещен для рутины. Все операции с файлами — только через silent tools (`view_file`, `replace_file_content`, `write_to_file`, `grep_search`).
2. Прямые, точечные изменения без затягивания времени.
3. Запретные зоны: `Archive/` (read-only), `docs/` и `git` (не трогать без прямого указания).
4. Запрещены переспрашивания и лишние вопросы в чате.
