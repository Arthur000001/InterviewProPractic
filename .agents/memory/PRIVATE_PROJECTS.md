* **Путь:** `/media/artur/BEA6-BBCE/InterviewPro/.notes/`
* **Назначение:** Закрытая база подготовки к реальным собеседованиям в конкретные IT-компании.
* **Структура:**
  - `index.html` — локальный дашборд со списком компаний (по умолчанию все аккордеоны свернуты).
  - `style.css` / `script.js` / `copy_code.js` — интерактивный движок (квизы, таймеры, режимы Mock-собеседований).

    - Критерии ответов по грейдам (Middle/Senior/TechLead).
    - `topic_summary.html` — полная сводная страница со всеми вопросами и интерактивными квизами.
  - `companies/flant/`:
    - 122 вопроса по Kubernetes, Linux, сетям, инцидентам и Go.
    - `topic_summary.html` — сводная страница с вопросами и квизами.
* **Правила работы:**
  - Никогда не называть сводные страницы `index.html` во избежание коллизий в Live Preview (только `topic_summary.html`).
  - Все правки вносить точечно через нативные файловые тулы без терминала (`run_command`).

### 2. 🎓 `teach/` — Персональный трек обучения Go (Go Fundamentals)
* **Путь:** `/media/artur/BEA6-BBCE/InterviewPro/teach/`
* **Назначение:** Интенсивный менторский курс для подготовки к Go-собеседованиям в сжатые сроки.
* **Ключевой фокус (`teach/MISSION.md`):**
  - Структуры, методы, интерфейсы и их взаимосвязь.
  - Value vs Pointer receiver и их влияние на method set.
  - Ловушки рантайма (`typed nil` в interface, `itable`, `iface`/`eface`).
  - Быстрая обратная связь, квизы и решение каверзных задач.
* **Структура:**
  - `lessons/` — учебные модули.
  - `learning-records/` — персональный трекинг прогресса и ответов.
  - `reference/` — справочные материалы.
